## Overview

Autism Prediction is an interactive web quiz for exploring autism spectrum traits through a short screening process. After the user responds to the questions, a machine learning model generates an informational result that can be viewed directly in the browser.

Because the app runs on the web, it offers a lightweight alternative to installing desktop software. The project also illustrates how a Random Forest model may be connected to an HTML-based application for health-related screening purposes.

---

## What It Includes

- A concise, interactive question flow
- Browser-based screening
- Prediction results generated with machine learning
- Random Forest model support
- Training based on the Autism Screening Adult dataset
- Clear presentation of informational results
- An integrated medical disclaimer

## Using the Quiz

1. Launch the application in a modern supported browser.
2. Complete the available screening questions.
3. Submit your answers to request the model-generated result.
4. Treat the displayed result as informational guidance rather than a diagnosis.
5. When appropriate, discuss the result with a qualified healthcare professional.

The interface is designed to keep the screening process brief and accessible from both desktop and mobile browsers.
